# Contributing

Read `AGENTS.md` and `docs/tasks/CURRENT_TASK.md` before editing. Work on a dedicated branch. Preserve deterministic puzzle logic and original assets. Keep every player-facing string English. Record test commands and outcomes in the PR; update the canonical task ledger. Do not commit secrets, release keystores, binaries or generated build outputs. Follow `docs/runbooks/development.md` and `docs/runbooks/testing.md`. Changes to live ads, purchases or analytics require explicit project approval.
